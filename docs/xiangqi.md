# 中国象棋 Document 设计与开发说明

## 功能边界与规则口径

中国象棋以普通、不可持久化的 `IPluginDocument` 接入 Host，稳定身份为
`myavalonia.plugin.classic.game.document.xiangqi`。每次打开 Document 都创建独立棋局；关闭后取消电脑与提示搜索并释放计时资源。

本游戏定位为**标准休闲中国象棋**：棋盘、棋子走法、红方先行、将军、应将、将死和困毙遵循标准中国象棋规则；重复局面采用
适合本地数字游戏的确定裁定，不宣称完整实现 2020 竞赛规则中的长杀、长捉、根子、联合捉和兑子价值棋例。

- 棋盘为 9 条纵线、10 条横线共 90 个交叉点，红黑双方各 16 子，红方先行。
- 帅将和仕士受九宫限制；相象走田、塞眼不走且不能过河；马走日、蹩腿不走；车直行不隔子；炮不吃子不隔子、吃子恰隔一架；
  兵卒未过河只前进，过河后可前进或横走，永不后退。
- 任何走后暴露己方帅将、未解除将军或造成将帅照面的着法均非法。对局在将死时结束，不允许真的吃掉帅将。
- 轮到的一方没有合法走法时，被将军为将死，未被将军为困毙，两者均判负。
- 相同“棋盘＋当前行棋方”第三次出现时：单方持续将军的第三次循环着法被拒并要求变着；双方持续将军或普通重复自动和棋。
- 连续 120 个半回合没有吃子自动和棋；吃子清零计数。将死和困毙优先于和棋条件。

首版支持本地双人和人机对战，可选择玩家执红或执黑，并提供简单、中等、困难三级电脑。辅助功能包含合法落点、稳定提示、
认输二次确认、决策点撤销、累计计时、标准中文棋谱和局内操作记录。不提供联网、存档、排行榜、持久战绩、残局题库、开局库、
AI 对 AI、外部 UCCI 引擎、独立双方棋钟、棋谱导入导出、音效或复杂动画。

## SOLID 职责与朴素设计

中国象棋与其他小游戏平级，保持独立领域：

```text
Features/Xiangqi/
├─ Domain/                 # 纯规则、不可变快照、中文记谱、撤销和三级 AI
├─ ViewModels/             # 模式、人机编排、计时、选择状态和展示投影
├─ Views/                  # AXAML、专用绘制控件和输入转发
└─ XiangqiDocument.cs      # Plugin SDK 生命周期适配器
```

| 组件 | 单一职责 | 明确不负责 |
| --- | --- | --- |
| `XiangqiRules` | 走法、攻击、将帅安全、终局、重复和局面键 | 撤销栈、AI 任务、计时和 UI |
| `XiangqiGame` | 持有当前快照、提交合法走法、认输和恢复历史 | 玩家模式、线程和展示文案 |
| `XiangqiGameSnapshot` | 隔离保存 90 点、回合、终局、无吃子计数和重复元数据 | 修改真实棋局 |
| `XiangqiNotation` | 把固定坐标转换为无歧义中文记谱 | 判断合法性和保存记录 |
| `IXiangqiMoveStrategy` | 从只读快照选择一着合法棋 | 提交走法、切换回合或操作 UI |
| `XiangqiGameTimer` | 基于 `TimeProvider` 累计有效时间 | UI 调度和胜负判断 |
| `XiangqiViewModel` | 命令、异步 AI、撤销、计时、记录和展示投影 | 重复实现领域规则 |
| `XiangqiBoardControl` | 绘制、正反坐标命中并转发交叉点 | 判断走法或修改领域对象 |
| `XiangqiDocument` | Host 标题、ViewModel 所有权和释放 | 游戏规则、命令和展示属性 |

只对确有多个生产实现和测试替身的电脑选步使用 Strategy 接口。撤销直接使用完整不可变快照栈，不建立 Memento 类层次；状态使用
枚举和显式终局原因，不引入 State 模式、事件总线、Mediator、仓储、抽象工厂或跨游戏通用棋盘框架。

领域规则、搜索恢复、重复周期等不直观实现使用详细中文 XML 注释说明“为什么”；简单属性和直观循环不写重复代码表面的空洞注释。

## 走子事务、将帅安全与撤销

一次领域走子按以下顺序完成：

1. 检查棋局未结束、坐标在盘内、起点属于当前方且终点没有己方棋子。
2. 按棋种检查九宫、河界、移动形状、马腿、象眼、直线路径或炮架。
3. 在棋盘副本上模拟走子；形成将帅照面或己方帅将仍受攻击时拒绝。
4. 生成“棋盘＋下一行棋方”的固定种子 Zobrist 键，同时保留完整签名以防哈希碰撞误判。
5. 若候选局面将第三次出现，检查最近重复周期双方的将军元数据；单方长将拒绝提交，其他重复继续提交并判和。
6. 保存走前不可变快照，一次写入移动、吃子、下一方、最近走法、步数、无吃子计数和局面记录。
7. 优先检查对方是否还有合法走法，产生将死或困毙；否则再检查三次重复和 120 半回合自然限着。

非法走法不改变棋盘、回合、步数、重复记录或撤销历史。快照在构造、复制和恢复时复制完整数组，后台 AI、历史和当前棋局不会共享
可变棋盘引用。

本地双人每次撤销一手。人机模式撤销到玩家上一个决策点：电脑已回应时回退电脑和玩家两手；电脑正在思考时先取消搜索，再只撤销
玩家刚走的一手；玩家执黑且尚未行动时不能撤销电脑的初始红棋。支持连续撤销，终局撤销后恢复对局，已经累计的耗时不倒扣。

## 中文棋谱

内部坐标始终为行 `0-9`、列 `0-8`，不随棋盘翻转改变。展示记谱遵守双方视角：红方线路使用中文数字，黑方线路使用阿拉伯数字。

- 平移记录目标线路，例如“炮二平五”。
- 车、炮、帅将、兵卒纵向进退记录步数，例如“车一进一”。
- 马、仕士、相象进退记录目标线路，例如“马8进7”。
- 同一路两个同类棋子用前/后，三个用前/中/后；四至五个同路兵卒用前、二、三、四、后稳定消歧。

ViewModel 保存坐标走法和格式化后的中文文本；提示只生成显示文本，不写棋谱；撤销删除相应正式着法，但保留一条撤销操作说明。

## 电脑、提示与计时

- **简单：** 优先一步将死；存在安全选择时排除会被对手一步将死的着法；其余按一层静态评价从前五候选带权随机。测试可注入固定随机源。
- **中等：** 600 毫秒、最多五层迭代加深 Minimax/Alpha-Beta，包含吃子和将军排序以及两层有限静态搜索。
- **困难：** 两秒、最多九层，共用同一正确性搜索核心并增加置换表、Killer Move、History Heuristic、有限将军延伸和六层静态搜索。

局面评价以车 900、炮 450、马 400、仕相 200、兵卒 100 为基础；过河兵、中心活动、将军和仕相完整度只作较小修正，避免位置奖励
压过真实强子得失。将死分远高于普通子力，并按深度偏好更短杀棋和更长逃杀。

AI 只接收不可变快照并创建单次搜索私有状态。时间或节点预算到达时返回最后完成深度；外部取消立即放弃结果。置换表键包含棋盘、
当前方和无吃子计数，搜索路径已经重复时不复用路径相关缓存。测试构造函数支持固定时间、深度和节点预算。

提示异步使用中等策略，只高亮建议起点和终点，不落子、不计步、不写记录。重新开始、配置切换、撤销、认输或释放 Document 都会取消
电脑和提示任务并增加棋局版本；旧任务完成后还必须匹配版本才能提交。

计时从第一手成功走棋开始，包含电脑思考时间；终局和空棋盘停止。`DispatcherTimer` 只刷新秒数，真实累计由 `TimeProvider` 计算。

## UI 与 Plugin 集成

- 专用控件绘制木色 9×10 网格、楚河汉界、九宫、圆形中文棋子和双方线路数字，不包含图片或第三方素材。
- 黄圈标记选中棋子，绿点/红圈标记合法空点/可吃目标，蓝圈标记最近走法，黄色线标记提示，红圈标记被将军的帅将。
- 玩家执黑时棋盘旋转 180 度，使玩家一方在下；绘制和命中只转换视图坐标，领域坐标保持不变。
- 工具栏提供模式、难度、玩家颜色、重新开始、撤销、提示和两次确认认输；人机选项在本地双人时隐藏。
- 状态区显示红黑剩余子数、总手数、当前方、用时、反馈和终局原因；右侧记录中文棋谱与操作事件。
- 工具区和记录区适配 Light/Dark 资源，木色棋盘保持稳定；较小窗口通过滚动区域承载固定比例棋盘。
- Plugin Module 将中国象棋注册为第五个普通 Document；Standalone 第五个页签复用正式 Document、ViewModel、View 和领域代码。

开发阶段只执行：

```powershell
dotnet restore
dotnet build -c Debug -warnaserror --no-restore
dotnet test -c Debug --no-build --no-restore
```

当前不是发布阶段，不增加或运行 Windows CI、Release 构建、ZIP 打包、Host 部署或发布门禁。本功能不使用 AIFLOW，不创建或修改
`.aiflow` 内容。

## 手工体验检查

1. 启动 Standalone 第五个“中国象棋”页签，确认标准布局、红方先手、楚河汉界、九宫和双方线路数字。
2. 逐项验证马腿、象眼、炮架、兵卒过河、九宫、将帅照面、将军、应将、将死和困毙反馈。
3. 切换三级人机和玩家红黑方，确认玩家执黑时电脑先行、棋盘翻转且电脑回合锁定输入。
4. 验证提示只高亮建议走法；本地单手撤销、人机决策点撤销、思考中撤销和连续撤销均恢复正确回合。
5. 构造单方长将、普通三次重复和 120 半回合未吃子，确认裁定、状态、计时和记录一致。
6. 验证标准中文棋谱、同路同类棋子消歧、二次确认认输和终局记录。
7. 在浅色、深色和较小窗口中确认棋盘、棋子、标记、工具栏和记录区清晰且可滚动。
8. 在真实 Host 打开多个中国象棋 Document，确认棋局、AI、提示、计时、记录和释放互不影响。
