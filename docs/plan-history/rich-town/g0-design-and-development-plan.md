规则实现、测试与完整模拟证据见 [G2 专项记录](g2-deterministic-rules.md)，不覆盖 G0/G1 的历史结果。

## 不可放宽的约束

- SOLID 为首要规定；普通组合、窄接口、枚举状态和快照优先，不为了模式而增加框架。
- 中文详细注释解释职责、设计思路、金额/坐标单位、线程、资源所有权、取消和失败路径。
- 新功能单测、原有游戏回归、Debug 警告即错误、覆盖率审查、格式、链接及本地集成验证必须配套。
- 不使用 AIFLOW，不读取或修改其内容。
- 不使用 Windows CI、Windows Smoke、Release Acceptance、Release 构建、正式 ZIP 打包或发布门禁。
- 不调用统一 `verify` / `seal` 或退役 G8/G10 脚本；未来发布任务另行执行发布检查。
- G1 后可显式生成 Debug 暂存目录，在隔离开发 Host 本地验证；这不是发布资格，不能覆盖日常 Host 和用户数据。
