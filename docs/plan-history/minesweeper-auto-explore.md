# ClassicGame 1.4.0：插旗后继续探索

日期：2026-10-14。基于已提交的 1.3.0 自动插旗功能，新增独立复选框，不改变只开启自动插旗时的原有行为。

## 最终行为

- “自动插旗”和“插旗后继续探索”默认均关闭，互不强制开启；后者单独使用时只依赖玩家现有旗帜。
- 两者同时开启时，每轮先插旗，再复用左键数字格的 `Chord` 展开，再让新数字参与下一轮插旗推理。
- 没有进展或对局结束即停止；不猜测、不扫描真实雷位、不纠正错旗，手动错旗仍可能踩雷。
- 开启选项、有效翻格和玩家补旗时运行辅助，取消旗帜不立即重新插回。
- 一次操作累计全部轮次的插旗数和翻格数，胜负后停止计时；重开及切难度保留选项并清零结果。

## 结构与验证

`MinesweeperGame.RunAutomation` 负责有限的迭代循环；展开复用现有 `Chord`，推雷仍使用纯可见快照推理器。
ViewModel 仅维护两个选项、累计统计、计时和投影，View 用两个独立的双向绑定复选框承载用户选择。

确定性用例覆盖多轮展开后新增插旗并获胜、只用手动旗帜、玩家补旗即展开、错旗踩雷、停滞退出、
开启即生效、重开/切难度、窗口隔离和释放后的操作。UI 用例验证两个复选框独立双向绑定及真实消息循环中的连锁获胜。
