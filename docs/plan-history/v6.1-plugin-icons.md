## 实现与边界

入口见 [真实 Module](../../src/ClassicGamePlugin.Plugin/Plugin/ClassicGamePluginModule.cs)。专属路径见 [PluginIcons](../../src/ClassicGamePlugin.Plugin/Plugin/PluginIcons.cs)。

模块在 Configure 内调用 `AddIcon`，使用注册返回值填入 `IconPath`，不手写所有者前缀。
矢量数据为不可变值，逻辑画布 20×20，采用 EvenOdd 填充；颜色、缩放和缓存由使用位置及 Host 决定。
执行真实模块组合的独立预览与测试注册器已适配可选图标接口，以本次实例字典记录图形并拒绝重复名称；
预览不建立 Host 的全局注册表、可用性治理或缓存，业务页面仍使用原有实例。

本插件全部为专属图形，不添加未使用的公共资源包依赖；跨 Host 边界只传 SDK 纯值描述。

dotnet build ClassicGamePlugin.slnx -c Release --no-restore -warnaserror -m:1

dotnet msbuild src/ClassicGamePlugin.Plugin/ClassicGamePlugin.Plugin.csproj -t:BuildManagedPluginPackage -p:Configuration=Release
