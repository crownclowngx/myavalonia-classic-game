## 实现与测试边界

纯推理器只接收已打开格的数字及可见旗帜，未知数字为空值；不读取真实雷位或隐藏数字。
用户进一步明确全部旗帜均按地雷计数，由玩家承担错旗的后果。因此规则为“数字减周围旗帜数”等于
未打开且未插旗的邻格数时，将这些邻格全部插旗；按坐标去重，幂等执行，不自动开格或纠正玩家旗帜。
开关默认关闭，开启立即分析，之后有效翻格再分析。关闭不撤旗，重开和切难度保留开关并清空结果。
准备、终局和释放后不执行推理。取消自动旗帜后，下次有效翻格或再次开启时才重新分析。

领域和 ViewModel 测试覆盖边角、重叠、信息不足、错旗、隐藏布局不变性、计时、终局、重开和多实例。
使用固定种子在三种棋盘尺寸分别生成 100 组含正确旗帜的公开信息，确认推导结果均为真实雷格。
另验证旗帜计数、旗帜超额和手动错旗导致快速展开踩雷，保留玩家承担后果的语义。
独立 `ClassicGamePlugin.UiTests` 使用 Avalonia 自有 UI 消息循环，验证开关双向绑定及浅/深色、600/1100 宽度渲染。
普通 xUnit 测试不排空 UI Dispatcher；既有魔方包装测试改为复用同仓绑定检查，实际视图创建由 Host 验收覆盖。
