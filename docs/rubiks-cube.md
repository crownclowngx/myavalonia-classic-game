# 三阶魔方 Document 设计与开发说明

## 功能边界与操作流程

三阶魔方以普通、不可持久化的 `IPluginDocument` 接入 Host，稳定身份为
`myavalonia.plugin.classic.game.document.rubiks-cube`，是本插件第十四个独立游戏。每个实例独占棋局、教学方案、
历史、播放器和求解取消源。Standalone 第十四个标签页直接复用正式插件代码。

1. 打开时显示已还原魔方，左键拖动观察、滚轮缩放，“恢复视角”恢复默认相机。
2. “打乱”在当前状态上执行 25 个随机转面指令，相邻指令不同面；先重置可从还原状态开始打乱。
3. 打乱完成后，后台按初学者层先法生成完整教学方案，并重放验证所有分组和最终结果。
4. “按照规则下一步”一次完成一个小目标：展示目的、情况、公式及完整操作流程，逐个播放全部动作，组末停止。
5. “连续还原”依次执行剩余各组；“暂停”在当前 90°结束后生效，“继续”恢复原播放方式。
6. “退回上一组”逆序播放该组动作，回到组起点；组内暂停则只逆放已经提交的动作前缀。随后点击下一步重看。
7. 下方六面按钮支持顺时针、逆时针、180°。手动操作后重新分析当前状态，旧方案不再适用。
8. “重置魔方”取消后台工作和播放，清空历史，立即恢复已还原状态。

界面使用中文，包含当前组、全部分组、预期与实际结果、打乱序列和操作记录。宽度小于 850 DIP 时改为上下布局。
金框标出目标小块，黄色弧箭头表示当前可见转面的方向，金色动作标记与当前动画同步。

首版不提供实体魔方颜色录入、CFOP、任意步骤跳转、联网、跨会话存档、音效或发布功能。观察操作不算转面。

## SOLID 职责与朴素设计

| 组件 | 单一职责 | 不负责 |
| --- | --- | --- |
| `CubeState` / `CubeRules` | 不可变贴纸身份、整数坐标、转面与阶段判定 | UI、线程、历史 |
| `CubeGame` | 唯一可变棋局、动作提交、版本与历史 | 求解、帧调度、三维投影 |
| `ICubeTeachingSolver` / `CubeTeachingSolver` | 从只读状态生成可验证教学方案 | 修改棋局、读取打乱历史 |
| `CubeAnimationPlan` | 300ms 四分之一转时间轴 | 计时器、提交状态 |
| `CubePlaybackController` | 串行动作、暂停/续播、完成后提交 | 公式识别、控件和布局 |
| `CubeTeachingText` / `CubeStepItem` | 中文目的、情况、公式与结果投影 | 修改规则、决定着法 |
| `RubiksCubeViewModel` | 页面命令、求解任务协调、教学游标与历史展示 | 旋转数学、公式搜索 |
| `CubeGeometry` / `RubiksCubeControl` | 几何、遮挡、相机和可见期间的帧驱动 | 求解或重复实现棋局 |
| `RubiksCubeDocument` | SDK 标题、命令适配、实例所有权和释放 | 游戏规则、绘制 |

SOLID 是实现和审查的首要约束。阶段公式目录和普通函数提供扩展点，播放器与绘制无需了解新增公式；
求解接口仅包含只读输入、取消和结果，默认实现与测试替身都不允许修改输入。ViewModel 构造参数注入求解器、
`TimeProvider`、随机源和 UI 调度函数，测试无需真实等待。

只使用既有 MVVM、一个求解策略接口、不可变快照和普通组合。状态采用枚举，历史采用列表；不引入事件总线、
Mediator、仓储、抽象工厂、状态类继承层次或跨游戏框架。公开表面仅为 Avalonia 绑定和既有 SDK 接入所必需的类型。
新增及修改注释使用中文，重点解释设计思路、职责、方向约定、阶段约束、提交边界和取消行为。

## 坐标与快照设计思路

固定持方：`U` 上黄、`R` 右橙、`F` 前绿、`D` 下白、`L` 左红、`B` 后蓝。`X` 指向右，`Y` 指向上，`Z` 指向前。
小块位置取 -1、0、1，排除核心位置后共有 26 个外部小块。54 个槽位由“小块位置 + 贴纸法线”唯一标识。
快照保存每张贴纸的永久身份，因而能完整推导小块身份、位置与朝向，不是仅保存六面颜色。

每个转面同时旋转该层的所有贴纸位置和法线；使用整数四分之一转置换，动画浮点误差不会进入状态。
正向表示从目标面外侧正视时的顺时针，对应绕外法线的负 90°旋转。`R'` 表示逆时针 90°；`R2` 保留为公式记号，
播放时展开为两个连续 `R`。相机拖动不修改领域坐标、公式或状态版本。

构造快照时复制数组并验证 54 张身份完整且互不重复。首版所有状态都从已还原状态经合法转面产生，未提供外部颜色输入。

## 层先法、公式与规则组

采用白色十字、底层角块、中层棱块、黄色十字、黄色面、顶角换位、顶棱换位七阶段。
参考 [Rubik's 官方教程](https://www.rubiks.com/solution-guides)、
[官方公式速查](https://coach.rubiks.com/en/quick-reference)及
[J Perm 初学者层先法说明](https://jperm.net/3x3)。教学文字为本项目根据真实状态生成的中文说明。

| 阶段 | 分组方式与公式 |
| --- | --- |
| 白色十字 | 每组归位一颗白棱并与中心色对齐；准备动作是常规六面转动 |
| 底角 | 每组归位一颗底角，使用 `R U R' U'` 和顶层对位，包括必要取出与重复 |
| 中层 | 每组归位一颗中棱；右插 `U R U' R' U' F' U F`，左插 `U' L' U L U F U' F'` |
| 黄色十字 | 顶层对位后执行 `F R U R' U' F'`，根据当前形态推进 |
| 黄色面 | 顶层对位后执行 `R U R' U R U2 R'`，纠正顶角朝向 |
| 顶角换位 | 对位和 `F' L F' R2 F L' F' R2 F2`，保持前两层与黄色面 |
| 顶棱换位 | `F2 U L R' F2 L' R U F2`，保持顶角、黄色面和前两层 |

每个公式提供四个水平面映射版本，实际字母按固定面标记展开，不隐含整颗魔方旋转。
前三阶段依次累计目标块，组末恢复已完成目标。有限情况表只跟踪这些目标块的位置和朝向，
反向建立情况到正向教学公式的映射；求解时只查当前快照。顶层搜索范围是朝向或置换情况，使用同一公式目录。
共享缓存只保存完整建成的只读整数情况表，不保存任何 Document、任务或棋局；取消中的表不进入缓存。

### 分组示例与验证

例如“归位白绿橙角块”是一组：说明该角块目前所在层，按次序列出顶层准备转动和底角插入公式，完整播放所有重复，
最后验证该角块及累计目标是否归位。即便中间暂时改变已完成小块，组结束时也必须恢复规定目标。

每组包含 `Stage`、目标块、完整公式列表、展开后的原子动作、`Before`、`After` 和累计保护目标。
准备动作、取出错误块、重复公式和末尾对齐均保留；不合并动作，也不消除相邻抵消动作。
公式清单逐次列出操作，摘要统计同一公式的次数。顶层过渡组明确说明“为下一组创造条件”，不会虚报整个阶段完成。

方案生成逐组检查保护条件并确认最终还原；ViewModel 接受结果前重新重放整套方案；实际播放结束再比较目标和快照。
任一检查失败都会清空不可用方案并停止继续执行。求解器完全不接收打乱或动作历史。

## 动画、回退与生命周期

三维模型包含黑色块体、六面贴纸与块间缝隙。目标层的块体和贴纸一起绕轴旋转；前后帧的着色均来自同一领域快照。
几何使用透视投影、背面剔除和多边形平面分割排序，避免旋转中间帧只按面中心深度排序而发生穿透。
默认投影比例按最大包围球留出边距，包含近端底角和所有转层中间帧；用户主动放大时允许观察局部。

- 默认每个 90°动作 **300ms**，缓入缓出；支持 0.5×、1×、2×。180°完整执行两个时间轴。
- UI 帧源约 16ms 一次，单次最多消费 50ms 墙钟时间，只推进当前动作；卡顿不会跳过公式动作。
- 动作结束才调用 `CubeGame.Commit` 一次，逻辑状态与当前完成的旋转一致；计数包含逆序回退实际执行的动作。
- 普通暂停在当前 90°结束后生效；连续模式在组末暂停也不会自动开始下一组。继续恢复原连续模式。
- 隐藏或移除 View 时冻结当前角度并停止帧源；再次显示后等待继续，不追赶隐藏期间的墙钟时间。
- 组内合法边界可逆放已提交前缀，完整组可逆放全组；回退后检查组起点并恢复原教学游标。
- 播放期间可以观察，打乱和手动操作仅在组边界开放；回退期间锁定其他动作，重置随时可用。
- 打乱或手动转面完成后取消旧求解并生成新方案。后台结果同时匹配取消源身份及棋局版本才可写回。
- Dispose 先关闭命令适配订阅，再取消求解、清理播放器；迟到回调不得更新关闭的 Document，重复释放安全。
- 动画帧与命令状态通知分离，只有可执行状态变化时才通知 Host，避免每帧重复投影重置菜单。

## UI、Plugin 与工作台集成

插件 Module 追加第十四个普通 Document，Standalone 追加对应标签页并显式释放。
工作台只增加 `myavalonia.plugin.classic.game.command.rubiks-cube.restart`，使用既有同步命令适配器，
Tools 菜单遵守当前实例路由。插件合计十四个 Document、二十三条命令和二十三个菜单贡献，快捷键数量保持两条。
逆序动画回退属于页面用例，不登记同步工作台 Undo。SDK、插件版本、Host 运行时接口及依赖包保持现状。

## 手工体验清单与开发边界

1. 观察六面正逆旋转和 180°，确认层有真实厚度、间隙和连续动作，贴纸随小块转动且遮挡正确。
2. 执行打乱、下一组、连续还原，核对目标高亮、公式标记和实际结果，确认全部动作和公式重复均可见。
3. 在动作途中和组末暂停、续播、回退；检查切换标签页后停留在原角度并等待继续。
4. 拖动观察、缩放、恢复视角，检查固定面标签、不同窗口尺寸与文字可读性。
5. 后续允许真实 Host 联调时，检查多个魔方 Document 独立运行、关闭和工作台重置路由。

本功能不使用 AIFLOW，不读取、创建或修改 `.aiflow` 内容。不新增或运行 Windows CI，不执行 Release 构建、
ZIP 打包、Host 部署、发布门禁或 `seal`；上述已发生的构建附带复制如实单列。当前统一 `verify` 包含 Release 和真实打包，
因此本阶段不调用它，也不改造主仓门禁框架。开发检查不代表发布验收；历史 G8/G10 文档保留原始验收事实。
